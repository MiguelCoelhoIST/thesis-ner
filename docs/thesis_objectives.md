# Thesis Objectives

## 1. Understand and reproduce the current system
- Analyze dataset and trained models
- Understand the current NER pipeline
- Reproduce a working baseline

## 2. Study current labels and limitations
- Identify existing entity types
- Analyze distribution of entities
- Understand model limitations

## 3. Extend model to legal-specific roles
- Arguido
- Réu
- Testemunha
- Relator

## 4. Explore synthetic data generation
- Generate new annotated examples
- Compare strategies (templates, LLMs, augmentation)
- Evaluate impact on performance

## 5. Experiment with transformer models
- Use current model as baseline
- Test alternative models
- Optionally use Hugging Face Trainer

## 6. Define evaluation process
- Create evaluation dataset
- Compare baseline vs extended vs new models
- Measure precision, recall, F1

## 7. Organize and document work
- Keep structure clean
- Track experiments
- Prepare thesis writing material
